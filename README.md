# Laboratório de Cibersegurança — Kali Linux e Medusa

## Sobre o projeto

Este repositório documenta meu aprendizado no desafio prático de cibersegurança da Digital Innovation One (DIO), utilizando Kali Linux e Medusa para compreender ataques de força bruta e medidas de prevenção.

O projeto será desenvolvido em um ambiente virtual controlado, com máquinas destinadas exclusivamente a testes educacionais.

## Objetivos

- Aprender os fundamentos de autenticação e ataques de força bruta.
- Conhecer as ferramentas Kali Linux e Medusa.
- Configurar e validar um laboratório isolado.
- Realizar simulações autorizadas com credenciais fictícias.
- Analisar riscos e recomendar medidas de segurança.
- Registrar a evolução do aprendizado e as evidências dos testes.

## Ferramentas

- Medusa
- Máquina virtual de laboratório
- GitHub para documentação
